# Changelog

## 0.9.3-beta

- Flèche visible dans l'en-tête pour ouvrir les modes directement dans DaliCount.
- Bouton de favori dédié sur chaque mode ; plus besoin de clic droit ni de commande pour les gérer.

## 0.9.2-beta

- Modes favoris enregistrés dans les paramètres de l'addon.
- Clic gauche sur la statistique pour parcourir uniquement les favoris.
- Clic droit pour afficher tous les modes et gérer les favoris.
- Commandes `/dc favorite <mode>` et `/dc favorites`.

## 0.9.1

- Nouvelle interface compacte inspirée des damage meters modernes.
- Nom DaliCount restauré dans l'en-tête.
- Barres de classement resserrées et fond plus transparent.
- Commandes secondaires atténuées hors survol.
- Largeur par défaut réduite et redimensionnement conservé.
- Partage du classement vers Groupe, Dire et Raid.

## 0.8.1-beta

- Première version publique.
- Dégâts, soins, DPS, HPS, absorptions et statistiques utilitaires.
- Détail des sorts hors combat.
- Compatibilité avec les valeurs protégées de WoW Forever.
